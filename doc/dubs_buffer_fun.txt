1. About this Plugin			*vim-buffer-delights-about*

About this Plugin~

Buffer and window navigation features for Vim.

- This plugin defines a bunch of window and buffer
  navigation commands — see the list below.

This plugin also defines a few automatic commands:

- Automatically jump to last known cursor position when
  opening a file.

- Enable `hidden` so buffers are not unloaded when abandoned.

Project page: https://github.com/embrace-vim/vim-buffer-delights#🍧

==============================================================================
1. Disable The Plugin			*vim-buffer-delights-disable*

Disable The Plugin~

If you'd just like to use the `autoload/` functions, or nothing
at all, set the following global to disable all command maps
and `plugin/` setup: >

  let g:vim_buffer_delights_disable = 1
<

3. Buffer-Related Commands		*vim-buffer-delights-buffer-cmds*

Switching MRU buffers~

				*<F2>*
<F2>			Toggle MRU Buffer. Load the previously-loaded
			buffer; used to quickly switch between two buffers.
			
Find buffers by name~

				c_<Shift-F2>* *c_<S-F2>*
<Shift-F2>		Show buffer list and prompt for number or (partial) name.
			Calls *:ls<CR>:b<Space>*

				*__*
__			A simple buffer list prompt similar to previous.

Related Vim commands~

These two commands are provided by Vim, not this plugin.
Just FYI, for comparison.

				*embrace:b*
:b {filename}		Switch to buffer by (partial) filename.

				*embrace:ls*
:ls 			List buffer numbers.

4. Window-Related Commands		*vim-buffer-delights-window-cmds*

Window-Related commands~

				*<Ctrl-Shift-Up>* *<C-S-Up>* *<C-W>W*
<Ctrl-Shift-Up>		Move Cursor to Window Above or Leftward.
			- Note: `mswin.vim` wires <Shift-Ctrl-Tab>
			  to same.

				*<Ctrl-Shift-Down>* *<C-S-Down>* *<C-W>w*
<Ctrl-Shift-Down>	Move Cursor to Window to Right or Below.
			- Note: `mswin.vim` wires <Ctrl-Tab>
			  to same.

				*vv*
vv			Creates a new vertical-split window, with the
			same buffer visible in each window.

Dubs Vim netrw Commands~

				*<Shift-Alt-@>* *<Shift-Alt-2>* *<Alt-@>* *<S-M-@>_* *<S-M-2>_* *<M-@>_*
<Shift-Alt-2>		Toggles the `netrw` `:Lexplore` window.

5. tmux-Compatible Navigation Commands	*vim-buffer-delights-tmux-cmds*

<Ctrl-Up/Down/PageUp/PageDown> window jumpers~

				*<Alt-Up>* *<M-Up>*
<Alt-Up>		Switch to Vim or tmux window above.

				*<Alt-Down>* *<M-Down>*
<Alt-Down>		Switch to Vim or tmux window below.

				*<Alt-PageUp>* *<M-PageUp>*
<Alt-PageUp>		Switch to Vim or tmux window leftward.

				*<Alt-PageDown>* *<M-PageDown>*
<Alt-PageDown>		Switch to Vim or tmux window rightward.

<Cmd-Ctrl-Up/Down/Left/Right> window jumpers~

				*<Cmd-Ctrl-Up>* *<T-C-Up>*
<Cmd-Ctrl-Up>		Switch to Vim or tmux window above.

				*<Cmd-Ctrl-Down>* *<T-C-Down>*
<Cmd-Ctrl-Down>		Switch to Vim or tmux window below.

				*<Cmd-Ctrl-Left>* *<T-C-Left>*
<Cmd-Ctrl-Left>		Switch to Vim or tmux window leftward.

				*<Cmd-Ctrl-Right>* *<T-C-Right>*
<Cmd-Ctrl-Right>	Switch to Vim or tmux window rightward.

<Cmd-Alt-Up/Down/Left/Right> window jumpers~

				*<Cmd-Alt-Up>* *<T-M-Up>*
<Cmd-Alt-Up>		Switch to Vim or tmux window above.

				*<Cmd-Alt-Down>* *<T-M-Down>*
<Cmd-Alt-Down>		Switch to Vim or tmux window below.

				*<Cmd-Alt-Left>* *<T-M-Left>*
<Cmd-Alt-Left>		Switch to Vim or tmux window leftward.

				*<Cmd-Alt-Right>* *<T-M-Right>*
<Cmd-Alt-Right>		Switch to Vim or tmux window rightward.

<Alt-Numpad/> window jumpers~

				*<Alt-8>* *<M-8>*
<Alt-8>			Switch to Vim or tmux window above.

				*<Alt-2>* *<M-2>*
<Alt-2>			Switch to Vim or tmux window below.

				*<Alt-4>* *<M-4>*
<Alt-4>			Switch to Vim or tmux window leftward.

				*<Alt-6>* *<M-6>*
<Alt-6>			Switch to Vim or tmux window rightward.

MRU window jumper~

				*<Alt-\>* *<M-\>*
<Alt-\>			Toggle focus between current and
			previously-focused window.

Cyclical window jumpers~

				*<Ctrl-Shift-Up>* *<C-S-Up>*
<Ctrl-Shift-Up>		Cycle focus counter-clockwise around windows.

				*<Ctrl-Shift-Down>* *<C-S-Down>*
<Ctrl-Shift-Down>	Cycle focus clockwise around windows.

==============================================================================
6. Tab-Related Navigation Commands	*vim-buffer-delights-tab-cmds*

Tab jumpers~

				*<Alt-Shift-Up>* *<M-S-Up>*
<Alt-Shift-Up>		Switch to previous tab page.
			- Same as |gt| in normal mode.
			- Same as <Ctrl-Alt-PageDown>.

				*<Alt-Shift-Down>* *<M-S-Down>*
<Alt-Shift-Down>	Switch to next tab page.
			- Same as |gT| in normal mode.
			- Same as <Ctrl-Alt-PageUp>.
